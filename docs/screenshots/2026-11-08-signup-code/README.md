# Ambassador code at signup (8 November 2026)

Before and after, on staging, for a teacher arriving through an ambassador's link (`/signup?code=...`).

| # | Screen | Before | After |
|---|---|---|---|
| 1 | Profile step, desktop ("Tell us who you are") | No mention of a code | An optional "Ambassador code" field, already filled in from the link and checked: "JAMIE... is a valid code". A wrong code says "not recognised" but never stops them signing up |
| 2 | Profile step, phone | Same | Same field, sized for a phone |
| 3 | Welcome screen after saving | The code sat in a box and was only recorded if the teacher pressed **Apply**. Skipping it lost the ambassador's credit | The code was already recorded on the profile step, before the trial started. The screen just confirms it: "Your code ... is on your account" |

Why it matters: most teachers subscribe after their free trial. The recorded code is what pays the ambassador their commission, whichever discount the teacher ends up using (their code, or the 50% end-of-trial offer, whichever saves the teacher more).
